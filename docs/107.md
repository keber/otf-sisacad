## Task AB#107: Create the TrainingProgramRepository repository

**Objective:** Create the data-access layer for the `TrainingProgram` entity through a JPA repository.

### Changes made

- Created the `TrainingProgramRepository` interface, extending `JpaRepository<TrainingProgram, Long>`.
- Implemented an **integration test** using `@DataJpaTest` and an embedded H2 database.
- Verified that a `TrainingProgram` object can be:
  - Saved correctly to the database.
  - Retrieved afterwards by its `id`.
  - Validated on its `code` and `name` attributes.

### Techniques applied

- Test Driven Development (TDD):
  - **RED:** An integration test was defined that failed because the repository was missing.
  - **GREEN:** `TrainingProgramRepository` was implemented until the test passed.
  - **REFACTOR:** No refactoring was needed at this stage.
- Flyway was used for the schema migration.
- A failed `ALTER TABLE` migration issue in H2 was resolved by consolidating the new fields into a clean initial migration.

### Result

- ✅ Integration test passing.
