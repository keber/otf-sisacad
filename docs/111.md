## Task AB#111 - Technical: Coverage Improvement and Technical Debt

## 🔢 Description

The goal of this task was to address aspects of **technical debt** identified during previous development tasks, in particular those reported by **SonarCloud** regarding code coverage and best practices.

It focused on classes that lacked sufficient tests or had no coverage at all, including:

* `ProgramaNoEncontradoException`
* `OtfSisacadApplication`
* `WebConfig`
* `ProgramaFormativoDTO`

## ✅ Activities carried out

### 1. ProgramaNoEncontradoException

* A direct unit test was implemented that verifies the message produced when throwing the exception includes the provided ID.

```java
@Test
void constructorIncluyeIdEnMensaje() {
    Long id = 99L;
    ProgramaNoEncontradoException ex = new ProgramaNoEncontradoException(id);
    assertTrue(ex.getMessage().contains("ID: " + id));
}
```

### 2. OtfSisacadApplication (Main)

* An assertion was added to the `mainRunsWithoutExceptions` test so that it is meaningful according to Sonar:

```java
@Test
void mainRunsWithoutExceptions() {
    assertDoesNotThrow(() -> OtfSisacadApplication.main(new String[]{}));
}
```

### 3. WebConfig

* A test was created to verify that the `ModelMapper` bean is created correctly:

```java
@Test
void modelMapperBeanDebeCrearse() {
    WebConfig config = new WebConfig();
    assertNotNull(config.modelMapper());
}
```

### 4. ProgramaFormativoDTO

* A test was added exercising field access and getter/setter usage to improve coverage:

```java
@Test
void gettersYSettersFuncionanCorrectamente() {
    ProgramaFormativoDTO dto = new ProgramaFormativoDTO();
    dto.setId(1L);
    dto.setCodigo("PF001");
    dto.setNombre("Programa A");
    dto.setFechaInicio(LocalDate.of(2024, 1, 1));
    dto.setFechaFin(LocalDate.of(2024, 12, 31));
    dto.setEstado("Activo");

    assertEquals("PF001", dto.getCodigo());
    assertEquals("Programa A", dto.getNombre());
}
```
