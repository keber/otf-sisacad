# Task AB#109 - Create the TrainingProgramController controller

## Objective

Implement the `TrainingProgramController` controller with the endpoints needed to expose the basic CRUD of the `TrainingProgram` entity, using a TDD approach (RED - GREEN - REFACTOR) and integration tests with `@WebMvcTest` and `MockMvc`.

---

## Endpoints implemented

| HTTP method | Path             | Description                       |
|-------------|------------------|----------------------------------|
| POST        | `/programs`      | Create a new training program    |
| GET         | `/programs`      | List all programs                |
| PUT         | `/programs/{id}` | Update an existing program       |
| DELETE      | `/programs/{id}` | Delete an existing program       |

## Issues found and resolved

- ❌ *Context load error* due to a missing `DataSource` in tests → resolved by using `@DataJpaTest` and adjusting the main class.
- ❌ *Jackson error (`releaseToPool()`)* → caused by mixed versions → resolved by updating and aligning the Jackson dependencies.
- ❌ *Binding error on `@PathVariable` parameters (`parameter name not available via reflection`)* → resolved with `-parameters` in the compiler.
- ✔️ All tests now pass correctly (`mvn test`).
