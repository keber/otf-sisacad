### ✅ Task AB#108 - Create the `TrainingProgramService` service

> **Superseded by Milestone 3.** This task is historically accurate and is kept
> for traceability. `TrainingProgram` is no longer a JPA entity — the domain
> model is separated from the JPA representation and JPA lives in
> `infrastructure.persistence`. See
> [`architecture/clean-architecture.md`](architecture/clean-architecture.md).

**Objective:**
Implement the service layer for the `TrainingProgram` entity, covering the basic CRUD operations using a TDD approach (RED - GREEN - REFACTOR).

---

#### 🔁 TDD cycles performed:

| Cycle    | Description                                                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| RED      | Unit tests were written for each operation: `save`, `findAll`, `findById`, `update`, `deleteById`.                                                    |
| GREEN    | The methods in `TrainingProgramService` that use `TrainingProgramRepository` were implemented.                                                      |
| REFACTOR | `update` was refactored to include ID-consistency validation and to throw the custom exception `TrainingProgramNotFoundException`.                   |

* `findAll()`

#### 🧼 Refactoring performed

* Removed redundant code by using `orElseThrow` to avoid the explicit `if/else`.
* Added explicit validation to prevent updates with inconsistent IDs.
* Created a custom exception `TrainingProgramNotFoundException` to improve traceability and error semantics.
