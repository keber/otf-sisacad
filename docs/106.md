## 🧩 Task AB#106 - Create the TrainingProgram class

> **Superseded by Milestone 3.** This task is historically accurate and is kept
> for traceability. `TrainingProgram` is no longer a JPA entity — the domain
> model is separated from the JPA representation and JPA lives in
> `infrastructure.persistence`. See
> [`architecture/clean-architecture.md`](architecture/clean-architecture.md).

### 🎯 Objective

Implement the `TrainingProgram` class as the base entity of the OTEC TuFuturo academic system, applying TDD principles, constructor-level validations, and JPA annotations for persistence. This class represents the training programs offered by the organization.

---

### 🔧 Activities carried out

- Defined the `TrainingProgram` class with the fields `id`, `code`, `name`, `startDate`, `endDate`, `status`.
- Applied the **RED-GREEN-REFACTOR** approach to implement:
  - Date validation (end date cannot be earlier than start date).
  - Null-field validation.
  - JPA annotations (@Entity, @Id, etc.).
- Refactored the constructor using helper methods.
- Wrote unit tests with JUnit to cover:
  - Valid cases
  - Cases with null values
  - Cases with inconsistent dates
  - Verification of JPA annotations
- Resolved conflicts from file duplication when moving the class to the correct package (`model`).
- Performed an interactive `rebase` to preserve traceability of the TDD steps.
- Integrated with `main` through a Pull Request and SonarCloud review, reaching high coverage with no significant technical debt.
